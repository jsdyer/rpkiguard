Reading the result

A Route Origin Authorization (ROA) names an AS that may originate an address block and can set a maximum prefix length. Validators turn signed ROAs into validated payloads (VRPs).

  • Valid. At least one covering entry authorizes the selected AS and permits the prefix length.
  • Invalid origin or length. A covering entry exists but no entry authorizes that exact pair.
  • Unknown. The validator had no covering entry. The result describes current origin authorization. Observed route history is a separate measurement.
